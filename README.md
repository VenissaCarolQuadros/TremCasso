# TremCasso

Tremor is a common movement disorder that can be caused by a number of medical conditions. Since tremor is often incurable, individuals with tremor rely on adaptive aids to accomplish simple everyday activities such as eating and writing.

This repository contains code for a Processing-based application designed for use with the Haply 2DIY force-feedback device. The application is a prototype for a haptic color picker, developed through an iterative design process aimed at improving accessibility for users with tremor.

Through this iterative approach, we identified a set of design principles that extend beyond the specific task of color selection. These principles have the potential to enhance the accessibility of digital interfaces, particularly in applications that involve selection and target acquisition. 

Read more about it in our [final report](https://venissacarolquadros.github.io/CanHap501/project/TremCasso.pdf).
